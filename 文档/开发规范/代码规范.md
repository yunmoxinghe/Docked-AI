# 代码规范

本文档定义 Docked AI 项目的代码风格和编码规范，确保代码库的一致性和可维护性。

---

## 🎯 核心原则

1. **可读性优先**：代码是写给人看的，其次才是给机器执行的
2. **一致性**：遵循统一的风格，降低认知负担
3. **简洁明了**：优先选择简单直接的实现
4. **性能意识**：在保持可读性的前提下优化性能

---

## 📝 命名约定

### C# 命名规范

#### 类、接口、方法、属性
```csharp
// 使用 PascalCase（帕斯卡命名法）
public class WindowManager { }
public interface IDialogService { }
public void InitializeWindow() { }
public string WindowTitle { get; set; }
```

#### 私有字段
```csharp
// 使用 camelCase，以下划线开头
private readonly ILogger _logger;
private string _currentState;
```

#### 参数、局部变量
```csharp
// 使用 camelCase
public void SetWindowSize(int width, int height)
{
    var windowHandle = GetHandle();
    string windowTitle = "Docked AI";
}
```

#### 常量
```csharp
// 使用 PascalCase
public const int MaxWindowWidth = 1920;
public const string DefaultTheme = "Light";
```

#### 枚举
```csharp
// 枚举类型和值都使用 PascalCase
public enum WindowState
{
    Normal,
    Minimized,
    Maximized,
    FullScreen
}
```

### 文件和目录命名

#### 目录名称
- **中文目录**：使用中文命名（符合项目约定）
  ```
  功能/
  功能/主窗口/
  功能/本地化/
  ```

#### 文件名称
- **中文文件名**：与代码类名保持一致，使用中文
  ```
  调试通知助手.cs
  主窗口.xaml.cs
  ```

## 🏗️ 代码结构

### 文件组织

每个 C# 文件应遵循以下结构：

```csharp
// 1. 文件头注释（可选）
// Copyright (c) Docked AI. All rights reserved.

// 2. using 语句（按字母顺序排列）
using System;
using System.Collections.Generic;
using Microsoft.UI.Xaml;
using Windows.Foundation;

// 3. 命名空间
namespace DockedAI.功能.主窗口
{
    // 4. 类定义
    /// <summary>
    /// 主窗口管理类
    /// </summary>
    public class MainWindow : Window
    {
        // 4.1 常量
        private const int DefaultWidth = 1200;
        
        // 4.2 静态字段
        private static readonly ILogger Logger = LoggerFactory.Create();
        
        // 4.3 私有字段
        private readonly DispatcherQueue _dispatcherQueue;
        private string _currentTheme;
        
        // 4.4 构造函数
        public MainWindow()
        {
            InitializeComponent();
        }
        
        // 4.5 公共属性
        public string Title { get; set; }
        
        // 4.6 公共方法
        public void Show()
        {
            // ...
        }
        
        // 4.7 受保护的方法
        protected virtual void OnClosed()
        {
            // ...
        }
        
        // 4.8 私有方法
        private void InitializeWindow()
        {
            // ...
        }
        
        // 4.9 事件处理器
        private void OnButtonClick(object sender, RoutedEventArgs e)
        {
            // ...
        }
    }
}
```

### 类设计原则

1. **单一职责**：每个类只负责一个功能领域
2. **合理大小**：单个类不超过 500 行（特殊情况除外）
3. **依赖注入**：通过构造函数注入依赖
4. **接口优先**：依赖接口而非具体实现

## 💡 编码风格

### 缩进和空格

```csharp
// 使用 4 个空格缩进，不使用 Tab
public void ExampleMethod()
{
    if (condition)
    {
        // 代码块
    }
}

// 操作符前后添加空格
var result = value1 + value2;
var isValid = (x > 0) && (y < 100);

// 逗号后添加空格
var list = new List<string> { "a", "b", "c" };
Method(param1, param2, param3);
```

### 大括号风格

```csharp
// 使用 K&R 风格（大括号另起一行）
public class Example
{
    public void Method()
    {
        if (condition)
        {
            // 代码
        }
        else
        {
            // 代码
        }
    }
}
```

### 换行规则

```csharp
// 方法签名过长时换行
public async Task<Result> ProcessDataAsync(
    string inputData,
    CancellationToken cancellationToken,
    IProgress<int> progress)
{
    // 方法体

// LINQ 查询换行

    .Where(x => x.IsActive)
    .OrderBy(x => x.Name)
    .Select(x => x.Id)
```

### 行内注释

```csharp
// 好的注释：解释为什么这样做
// 使用 DispatcherQueue 确保在 UI 线程执行，避免跨线程异常
_dispatcherQueue.TryEnqueue(() => UpdateUI());

```

## 🎨 WinUI 3 特定规范

### XAML 命名

```xml
<!-- 控件命名使用 PascalCase，有意义的描述性名称 -->
<Button x:Name="SubmitButton" />
<TextBox x:Name="UserNameTextBox" />
<ListView x:Name="ChatMessagesListView" />
```

### 事件处理

```csharp
// 事件处理器命名：On + 控件名 + 事件名
private void OnSubmitButtonClick(object sender, RoutedEventArgs e)
{
    // 处理点击事件
}

private void OnUserNameTextBoxTextChanged(object sender, TextChangedEventArgs e)
{
    // 处理文本变化
}
```

### 线程管理

```csharp
// 必须使用 DispatcherQueue 进行 UI 线程调度
_dispatcherQueue.TryEnqueue(() =>
{
    // UI 更新操作
    StatusText.Text = "更新完成";
});

// 避免在 UI 线程执行耗时操作
Task.Run(async () =>
{
    var result = await LongRunningOperationAsync();
    
    // 切换回 UI 线程更新界面
    _dispatcherQueue.TryEnqueue(() =>
    {
        UpdateUI(result);
    });
});
```

## 🚀 Native AOT 兼容性

### 避免反射

```csharp
// ❌ 不好：使用反射
var type = Type.GetType("DockedAI.MyClass");
var method = type.GetMethod("MyMethod");
method.Invoke(instance, null);

// ✅ 好：直接调用
var instance = new MyClass();
instance.MyMethod();
```

### 避免动态类型

```csharp
// ❌ 不好：使用 dynamic
dynamic obj = GetObject();
obj.SomeMethod();

// ✅ 好：使用明确的类型
IMyInterface obj = GetObject();
obj.SomeMethod();
```

### 使用源生成器

```csharp
// 使用 JSON 源生成器代替反射
[JsonSerializable(typeof(MyData))]
public partial class MyJsonContext : JsonSerializerContext { }

// 序列化时使用
var json = JsonSerializer.Serialize(data, MyJsonContext.Default.MyData);
```

### 字符串资源

