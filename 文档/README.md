## 📝 文档维护规则

1. **及时更新**：完成功能或修复 bug 后立即更新相关文档
2. **清晰标注**：使用日期和版本号标记重要变更
3. **关联引用**：在文档间建立清晰的引用链接
4. **中文优先**：所有文档使用中文编写，符合项目约定

## 🔄 文档更新流程

### 修改现有文档
1. 直接编辑对应的 `.md` 文件
2. 更新文档末尾的"最后更新"日期
3. 如有重大变更，在文档中添加更新记录

### 新增文档（需授权）
1. 先征得哥哥明确同意
2. 确认文档应归属的子目录（项目进度/Bug追踪/开发规范等）
3. 使用统一的 Markdown 格式编写
4. 更新对应子目录的导航文档
5. 在本 README 中添加链接

## 🎨 文档格式规范

### Markdown 规范
- 使用标准 Markdown 语法
- 标题层级清晰（`#` ~ `####`）
- 代码块标注语言类型
- 表格对齐整齐
- 链接使用相对路径

### 文件头模板
```markdown

> 简短的文档说明

```
