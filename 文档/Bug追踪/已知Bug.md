## 🐛 Bug 记录示例

> 以下是 bug 记录的格式示例，实际 bug 请在上方对应严重级别区域添加

### 🐛 [BUG-20260620-001] 示例：窗口启动延迟

| 项目 | 内容 |
|------|------|
| **Bug ID** | BUG-20260620-001 |
| **严重程度** | 🟡 中等 |
| **优先级** | P2-中 |
| **状态** | 🆕 新建 |
| **报告日期** | 2026-06-20 |
| **报告人** | 用户A |
| **影响版本** | v0.3.0 |
| **模块** | 窗口管理 |
| **类型** | 性能问题 |

**问题描述**：  
应用启动时，窗口显示有 2-3 秒延迟，在低配置机器上更明显。

**复现步骤**：
1. 在低配置机器上运行应用
2. 观察从进程启动到窗口显示的时间

**复现频率**：经常复现（>50%）

**影响范围**：
- 影响首次启动体验
- 在低配置机器上更明显

**可能原因**：
- [ ] 初始化加载项过多
- [ ] 同步 I/O 操作阻塞
- [ ] 资源加载未优化

**临时解决方案**：  
使用 Release 配置构建，启动速度稍快。

**备注**：  
需要进行性能分析，找出启动瓶颈。
