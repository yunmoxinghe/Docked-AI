## 🐛 问题描述

### 详细描述
清楚、完整地描述遇到的问题。

例如：
```
应用启动后，主窗口没有显示在屏幕上。进程在任务管理器中可见，
但没有可见的窗口界面。日志中显示窗口已创建，但用户无法看到。
```

### 预期行为
描述应该发生什么。

例如：
```
应用启动后，应该在屏幕中央显示主窗口，窗口大小为 1200x800，
包含导航栏和主内容区域。
```

### 实际行为
描述实际发生了什么。

例如：
```
应用启动后，没有任何窗口显示，但进程正在运行。
系统托盘也没有显示应用图标。
```
