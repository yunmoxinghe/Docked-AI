# 应用评价功能实现说明

## 已完成的功能

### 1. 核心服务类
**文件**: `StoreRatingService.cs`

提供三种评价方式：
- ✅ **应用内评价**（推荐）：使用 `StoreContext.RequestRateAndReviewAppAsync()`
- ✅ **跳转商店评价**：使用 `Launcher.LaunchUriAsync()` 打开 Store 评价页
- ✅ **智能评价**：自动选择最佳方式，优先应用内评价，失败则跳转商店

### 2. 设置页面集成
**文件**: `功能\页面\设置\设置页面.xaml` 和 `设置页面.xaml.cs`

在设置页面的"关于"部分添加了评价卡片：
- 📍 位置：关于 → 展开后的第一项
- 🎨 图标：星星图标 (&#xE735;)
- 📝 文本：
  - 标题："评价应用"
  - 描述："喜欢这个应用吗？给我们评分和评论吧！"
- 🔗 点击后调用 `StoreRatingService.RequestRatingAsync()`

### 3. 托盘菜单集成
**文件**: `功能\统一调用\托盘右键菜单\TrayContextMenuService.cs` 和 `功能\托盘\TrayMenus.xaml`

在托盘右键菜单中添加了评价选项：
- 📍 位置：重启应用 和 退出 之间
- 🎨 图标：星星图标 (&#xE735;)
- 📝 文本："评价应用"
- 支持鼠标模式和触摸模式两种菜单

### 4. 本地化支持
已添加中文和英文本地化字符串：

**中文** (`zh-CN/Resources.resw`):
- `TrayMenu_RateApp`: "评价应用"

- `SettingsPage_RateAppCard.Description`: "喜欢这个应用吗？给我们评分和评论吧！"

**英文** (`en-US/Resources.resw`):

## 使用方式

### 用户视角
1. **设置页面**：打开设置 → 滚动到"关于"部分 → 展开 → 点击"评价应用"
2. **托盘菜单**：右键点击托盘图标 → 点击"评价应用"

### 开发者视角
```csharp
// 在任何地方调用
using Docked_AI.功能.统一调用.应用评价;

// 智能评价（推荐）
await StoreRatingService.RequestRatingAsync();

// 仅应用内评价
var status = await StoreRatingService.ShowInAppRatingDialogAsync();

// 仅跳转商店
await StoreRatingService.LaunchStoreReviewPageAsync();
```

## 技术细节

### 应用内评价工作原理
1. 调用 `StoreContext.RequestRateAndReviewAppAsync()`
2. 系统弹出原生评价对话框
3. 用户可以直接打分和写评论
4. 无需离开应用

### 降级策略
- 开发环境中，应用内评价会返回 `Error` 状态
- 自动降级到跳转 Microsoft Store 评价页面
- 确保在任何环境下都能触发评价流程

### 商店信息
- **Product ID**: `9NX1DZB3WNWP`
- **Store 链接**: https://www.microsoft.com/store/apps/9NX1DZB3WNWP

## 最佳实践

### ✅ 推荐做法
- 在用户完成重要操作后提示评价
- 在用户表现出满意时提示评价
- 记录用户是否已评价，避免重复提示

### ❌ 避免做法
- 不要在应用启动时立即提示
- 不要在用户遇到错误时提示
- 不要频繁弹出评价请求
