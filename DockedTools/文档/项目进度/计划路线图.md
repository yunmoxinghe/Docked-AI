# 项目路线图

本文档规划 DockedTools 项目的未来发展方向和功能计划。

## 🗺️ 整体规划

### 愿景
打造一个智能、高效、美观的 Windows 桌面 AI 助手应用，为开发者提供强大的辅助能力。

### 核心价值
- **智能辅助**：集成多种 AI 技能，提供专业领域支持
- **原生体验**：充分利用 WinUI 3 和 Windows 11 特性
- **开发友好**：为开发者优化的工具和工作流
