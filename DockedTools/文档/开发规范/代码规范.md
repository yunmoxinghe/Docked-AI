# 代码规范

本文档定义 DockedTools 项目的代码风格和编码规范，确保代码库的一致性和可维护性。

---

## 🎯 核心原则

1. **可读性优先**：代码是写给人看的，其次才是给机器执行的
2. **一致性**：遵循统一的风格，降低认知负担
3. **简洁明了**：优先选择简单直接的实现
4. **性能意识**：在保持可读性的前提下优化性能

---

## 📝 命名约定

### C# 命名规范

#### 类、接口、方法、属性
```csharp
// 使用 PascalCase（帕斯卡命名法）
public class WindowManager { }
public interface IDialogService { }
public void InitializeWindow() { }
public string WindowTitle { get; set; }
```

#### 私有字段
```csharp
// 使用 camelCase，以下划线开头
private readonly ILogger _logger;
private string _currentState;
```

#### 参数、局部变量
```csharp
// 使用 camelCase
public void SetWindowSize(int width, int height)
{
    var windowHandle = GetHandle();

```

#### 常量
```csharp
// 使用 PascalCase
public const int MaxWindowWidth = 1920;

```

#### 枚举
```csharp
// 枚举类型和值都使用 PascalCase
public enum WindowState
{

    Maximized,
    FullScreen

```

#### 目录名称

### 文件组织

每个 C# 文件应遵循以下结构：

```csharp
// 1. 文件头注释（可选）
// Copyright (c) DockedTools. All rights reserved.

// 2. using 语句（按字母顺序排列）
using System;

// 3. 命名空间
namespace DockedAI.功能.主窗口

    /// </summary>
    public class MainWindow : Window
    {
        // 4.1 常量
        private const int DefaultWidth = 1200;
        
        // 4.2 静态字段
        private static readonly ILogger Logger = LoggerFactory.Create();
        
        // 4.3 私有字段
        private readonly DispatcherQueue _dispatcherQueue;
        private string _currentTheme;
        
        // 4.4 构造函数
        public MainWindow()
        {
            InitializeComponent();
        }
        
        // 4.5 公共属性
        public string Title { get; set; }
        
        // 4.6 公共方法
        public void Show()
        {
            // ...
        }
        
        // 4.7 受保护的方法
        protected virtual void OnClosed()
        {
            // ...
        }
        
        // 4.8 私有方法
        private void InitializeWindow()
        {
            // ...
        }
        
        // 4.9 事件处理器
        private void OnButtonClick(object sender, RoutedEventArgs e)
        {
            // ...
        }
    }

```

### 类设计原则

1. **单一职责**：每个类只负责一个功能领域
2. **合理大小**：单个类不超过 500 行（特殊情况除外）
3. **依赖注入**：通过构造函数注入依赖
4. **接口优先**：依赖接口而非具体实现

## 🚀 Native AOT 兼容性

> **重要**：本项目支持 Native AOT 编译以获得更快的启动速度和更小的内存占用。所有新增代码必须确保 AOT 兼容。

### 1. 避免反射

```csharp
// ❌ 不好：使用反射
var type = Type.GetType("DockedAI.MyClass");
var method = type.GetMethod("MyMethod");
method.Invoke(instance, null);

// ✅ 好：直接调用
var instance = new MyClass();
instance.MyMethod();
```

### 2. 避免动态类型

```csharp
// ❌ 不好：使用 dynamic
dynamic obj = GetObject();
obj.SomeMethod();

// ✅ 好：使用明确的类型
IMyInterface obj = GetObject();
obj.SomeMethod();
```

### 3. 使用 Regex 源生成器 ⭐ 必须遵守

**问题**：运行时构造的 `Regex` 在 Native AOT 中会触发 IL3050 警告，且 `RegexOptions.Compiled` 会抛出异常。

**解决方案**：使用 `GeneratedRegex` 特性（.NET 7+ 特性）

```csharp
// ❌ 不好：运行时构造 Regex
public class HtmlParser
{
    public string ParseTitle(string html)
    {
        var match = Regex.Match(html, "<title>(.*?)</title>", RegexOptions.IgnoreCase);
        return match.Success ? match.Groups[1].Value : string.Empty;
    }
}

// ✅ 好：使用源生成的 Regex
public partial class HtmlParser
{
    [GeneratedRegex("<title>(.*?)</title>", RegexOptions.IgnoreCase)]
    private static partial Regex TitleRegex();
    
    public string ParseTitle(string html)
    {
        var match = TitleRegex().Match(html);
        return match.Success ? match.Groups[1].Value : string.Empty;
    }
}
```

**常见正则表达式源生成模板**：

```csharp
public sealed partial class MyClass
{
    // 匹配 HTML 标签
    [GeneratedRegex("<([a-z]+)[^>]*>", RegexOptions.IgnoreCase)]
    private static partial Regex HtmlTagRegex();
    
    // 匹配空白字符
    [GeneratedRegex("\\s+")]
    private static partial Regex WhitespaceRegex();
    
    // 匹配数字格式（如 1920x1080）
    [GeneratedRegex("(\\d+)x(\\d+)", RegexOptions.IgnoreCase)]
    private static partial Regex SizeFormatRegex();
    
    // 匹配 HTML 属性（带引号）
    [GeneratedRegex("(['\"])(.*?)\\1", RegexOptions.IgnoreCase | RegexOptions.Singleline)]
    private static partial Regex HtmlAttributeRegex();
}
```

### 4. 使用 JSON 源生成器（推荐）

**问题**：`JsonSerializer.Deserialize<T>()` 在 Native AOT 中可能触发 IL2026 警告。

**解决方案**：使用 `JsonSerializerContext` 源生成器

```csharp
// ❌ 可以工作但不推荐：反射序列化
var data = JsonSerializer.Deserialize<MyData>(json);

// ✅ 推荐：使用源生成器
[JsonSourceGenerationOptions(WriteIndented = false)]
[JsonSerializable(typeof(MyData))]
[JsonSerializable(typeof(List<MyData>))]
internal partial class AppJsonContext : JsonSerializerContext { }

// 序列化/反序列化时使用
var json = JsonSerializer.Serialize(data, AppJsonContext.Default.MyData);
var data = JsonSerializer.Deserialize(json, AppJsonContext.Default.MyData);
```

**JsonDocument 手动解析**（完全 AOT 兼容）：

```csharp
// ✅ 完全 AOT 兼容：手动遍历 JsonElement
var jsonDoc = JsonDocument.Parse(jsonString);
if (jsonDoc.RootElement.TryGetProperty("name", out var nameElement))
{
    string name = nameElement.GetString() ?? "";
}
```

### 5. 使用 LibraryImport 代替 DllImport

```csharp
// ❌ 旧方式：DllImport（仍可用但不推荐）
[DllImport("user32.dll", SetLastError = true)]
private static extern IntPtr GetForegroundWindow();

// ✅ 新方式：LibraryImport（.NET 7+，完全 AOT 兼容）
[LibraryImport("user32.dll")]
private static partial IntPtr GetForegroundWindow();

// ✅ 带参数和返回值编组
[LibraryImport("user32.dll", StringMarshalling = StringMarshalling.Utf16)]
[return: MarshalAs(UnmanagedType.Bool)]
private static partial bool SetWindowText(IntPtr hWnd, string lpString);
```

### 6. SQLite 数据库访问

**Microsoft.Data.Sqlite** 从 7.0+ 版本完全支持 Native AOT：

```csharp
// ✅ AOT 兼容：使用参数化查询
using var connection = new SqliteConnection(connectionString);
connection.Open();

using var command = connection.CreateCommand();
command.CommandText = "SELECT * FROM users WHERE id = @id";
command.Parameters.AddWithValue("@id", userId);

using var reader = command.ExecuteReader();
while (reader.Read())
{
    var name = reader.GetString(0);
}
```

### 7. WinRT 互操作

**CsWinRT** 从 2.0+ 版本完全支持 Native AOT：

```csharp
// ✅ AOT 兼容：WinRT 投影自动支持
var picker = new FileOpenPicker();
picker.FileTypeFilter.Add(".png");

IntPtr hwnd = GetForegroundWindow();
WinRT.Interop.InitializeWithWindow.Initialize(picker, hwnd);
var file = await picker.PickSingleFileAsync();
```

### 8. AOT 兼容性检查清单

**提交代码前必须确认**：

- [ ] 没有使用运行时 `Regex` 构造（使用 `GeneratedRegex` 代替）
- [ ] 没有使用反射（`Type.GetType()`, `MethodInfo.Invoke()` 等）
- [ ] 没有使用 `dynamic` 类型
- [ ] JSON 序列化使用 `JsonDocument` 或 `JsonSerializerContext`
- [ ] P/Invoke 使用 `LibraryImport` 而非 `DllImport`
- [ ] 没有使用 `Assembly.Load()` 或 `Activator.CreateInstance()`
- [ ] 构建时没有 IL2026、IL3050、IL3051 警告

### 9. 真实修复案例：网页应用页面 AOT 兼容性

**日期**：2026-06-20  
**文件**：`功能/页面/网页应用/网页应用页面.xaml.cs`

**问题**：4 处运行时 `Regex` 调用导致 AOT 不兼容

**修复前**：
```csharp
Match titleMatch = Regex.Match(html, "<title[^>]*>(.*?)</title>", 
    RegexOptions.IgnoreCase | RegexOptions.Singleline);
```

**修复后**：
```csharp
// 类顶部定义源生成的正则表达式
[GeneratedRegex("<title[^>]*>(.*?)</title>", RegexOptions.IgnoreCase | RegexOptions.Singleline)]
private static partial Regex TitleRegex();

// 使用时直接调用
Match titleMatch = TitleRegex().Match(html);
```

