# MainWindowService 使用示例

## 基础用法

### 1. 查询当前窗口状态

```csharp
using DockedTools.Features.UnifiedCalls.MainWindow;

// 获取当前状态枚举
var currentState = MainWindowService.CurrentState;

// 检查具体状态
if (MainWindowService.IsVisible)
{
    // 窗口可见
}

if (MainWindowService.IsPinned)
{
    // 窗口处于固定模式
}

if (MainWindowService.IsMaximized)
{
    // 窗口最大化
}
```

### 2. 申请改变窗口状态

```csharp
// 切换显示/隐藏
MainWindowService.RequestToggleWindow();

// 切换固定/取消固定
MainWindowService.RequestTogglePinned();

// 切换最大化/还原
MainWindowService.RequestToggleMaximize();

// 直接显示窗口（如果当前隐藏）
MainWindowService.RequestShow();

// 直接隐藏窗口（如果当前可见且未固定）
MainWindowService.RequestHide();
```

### 3. 订阅状态变化通知

```csharp
// 订阅状态开始变化事件（动画开始时）
MainWindowService.StateChanged += OnMainWindowStateChanged;

private void OnMainWindowStateChanged(object? sender, StateChangedEventArgs args)
{
    Debug.WriteLine($"窗口状态开始变化：{args.PreviousState} -> {args.CurrentState}");
    Debug.WriteLine($"变化原因：{args.Reason}");
    // 注意：此时动画可能还在播放
}

// ⭐ 推荐：订阅状态完成事件（动画完成后）
MainWindowService.StateCompleted += OnMainWindowStateCompleted;

private void OnMainWindowStateCompleted(object? sender, StateCompletedEventArgs args)
{
    Debug.WriteLine($"窗口状态变化完成：{args.PreviousState} -> {args.CurrentState}");
    
    // ✅ 动画已完成，可以安全地执行依赖窗口显示的操作
    switch (args.CurrentState)
    {
        case WindowState.Pinned:
            // 窗口已固定且动画完成
            StartMonitoringService();
            break;
            
        case WindowState.Hidden:
            // 窗口已隐藏且动画完成
            PauseBackgroundTasks();
            break;
            
        case WindowState.Maximized:
            // 窗口已最大化且动画完成
            ExpandContentArea();
            break;
            
        case WindowState.Windowed:
            // 窗口已显示且动画完成
            if (args.PreviousState == WindowState.Hidden)
            {
                // 从隐藏恢复显示，可以设置焦点等操作
                SetFocusToInput();
            }
            break;
    }
}

// 记得在清理时取消订阅
private void Cleanup()
{
    MainWindowService.StateChanged -= OnMainWindowStateChanged;
    MainWindowService.StateCompleted -= OnMainWindowStateCompleted;
}
```

## 实际应用场景

```csharp
private void PinButton_Click(object sender, RoutedEventArgs e)

private void MaximizeButton_Click(object sender, RoutedEventArgs e)
{
    MainWindowService.RequestToggleMaximize();

```

### 场景 2：根据窗口状态更新 UI

```csharp
// 在页面加载时检查窗口状态
private void Page_Loaded(object sender, RoutedEventArgs e)
{
    // 根据窗口状态调整 UI
    if (MainWindowService.IsPinned)
    {
        // 固定模式下，显示特定的提示或功能
        PinnedModeIndicator.Visibility = Visibility.Visible;
        EnableAdvancedFeatures();
    }
    
    if (MainWindowService.IsMaximized)
    {
        // 最大化时，使用更宽的布局
        ContentGrid.Width = Double.NaN; // 自动宽度
    }
}
```

### 场景 5：自动化脚本

```csharp
// 在自动化测试或启动脚本中
public async Task StartupSequence()
{
    // 等待窗口创建
    while (MainWindowService.CurrentState == WindowState.NotCreated)
    {
        await Task.Delay(100);
    }
    
    // 显示窗口
    MainWindowService.RequestShow();
    
    // 等待窗口可见
    while (!MainWindowService.IsVisible)
    {
        await Task.Delay(100);
    }
    
    // 执行其他初始化操作
    InitializeFeatures();
}
```

### 场景 6：条件性状态变更

```csharp
// 智能状态管理
private void OnUserIdleDetected()
{
    // 用户空闲时，如果窗口未固定则隐藏
    if (MainWindowService.IsVisible && !MainWindowService.IsPinned)
    {
        MainWindowService.RequestHide();
    }
}

private void OnUrgentNotification()
{
    // 紧急通知时，如果窗口隐藏则显示
    if (MainWindowService.IsHidden)
    {
        MainWindowService.RequestShow();
    }
}
```

## 注意事项

1. **异步执行**：所有状态变更请求都是异步执行的，不会阻塞调用线程
2. **状态验证**：在请求前可以检查当前状态，避免无效操作
3. **事件订阅**：记得在不需要时取消订阅事件，避免内存泄漏
4. **线程安全**：服务内部处理了线程同步，可以在任何线程安全调用
5. **失败处理**：状态变更可能失败（如正在执行其他转换），通过订阅 StateChanged 事件确认结果

## 状态枚举说明

```csharp
WindowState.NotCreated  // 窗口尚未创建
WindowState.Hidden      // 窗口已隐藏
WindowState.Windowed    // 窗口化模式（标准停靠）
WindowState.Maximized   // 最大化模式
WindowState.Pinned      // 固定模式（AppBar）
```

## 调试技巧

```csharp
// 在调试时输出状态信息
private void LogWindowState()
{
    Debug.WriteLine($"窗口状态：{MainWindowService.CurrentState}");
    Debug.WriteLine($"可见：{MainWindowService.IsVisible}");
    Debug.WriteLine($"固定：{MainWindowService.IsPinned}");
    Debug.WriteLine($"最大化：{MainWindowService.IsMaximized}");
}

// 监控所有状态变化
MainWindowService.StateChanged += (sender, args) =>
{
    Debug.WriteLine($"[{args.Timestamp:HH:mm:ss.fff}] {args.PreviousState} -> {args.CurrentState} ({args.Reason})");
};
```
